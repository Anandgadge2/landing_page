## 📖 Overview

**NEXORA** blends radical engineering with haute digital aesthetics. Designed to deliver an unforgettable first impression, the platform employs mathematical canvas animations, interactive bento grids with dynamic cursor tracking, physics-driven particle constellations, and smooth stateful micro-interactions.

Built from the ground up using **React 19**, **Vite 8**, **Tailwind CSS**, and **Framer Motion**, NEXORA represents the pinnacle of modern web design: ultra-performant, responsive across all viewports, and visually breathtaking.

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed on your machine:
- **Node.js**: `v18.0.0` or higher (Node 20+ recommended)
- **npm**: `v9.0.0` or higher (or `pnpm` / `yarn`)

### Installation

1. Clone the repository to your local environment:
   ```bash
   git clone https://github.com/Anandgadge2/landing_page.git
   cd landing_page/Nexora
   ```

2. Install project dependencies:
   ```bash
   npm install
   ```

3. Launch the local development server:
   ```bash
   npm run dev
   ```
   The application will be live at `http://localhost:5173`.

In the project directory, you can run:

## 🎨 Configuration & Customization

### 1. Color Palette & Theming
Customize or extend the brand aesthetic directly inside [`tailwind.config.js`](file:///e:/landing_page/Nexora/tailwind.config.js):
```javascript
// tailwind.config.js
colors: {
  nexora: {
    950: '#030206', // Base obsidian canvas
    900: '#06050b', // Card surface dark
    850: '#0a0815', // Card surface medium
    violet: '#8b5cf6', // Primary accent
    purple: '#a855f7', // Secondary accent
    cyan: '#06b6d4',   // Electric contrast
  }
}
```

### 2. Particle & 3D Physics Adjustment
- **Cosmic Particles**: Modify particle density, speed, and connection distance in [`src/components/BackgroundCanvas.jsx`](file:///e:/landing_page/Nexora/src/components/BackgroundCanvas.jsx).
- **Holographic 3D Orb**: Adjust ring count, rotation speed, and perspective focal length in [`src/components/Hero.jsx`](file:///e:/landing_page/Nexora/src/components/Hero.jsx).

## ⚡ Performance & Quality

- **Production Footprint**: Highly optimized bundle with gzipped CSS under ~10 kB and gzipped JS under ~140 kB.
- **Accessible & Semantic**: Uses semantic HTML5 landmarks (`<main>`, `<section>`, `<nav>`, `<footer>`, `<h1>`-`<h3>`), ARIA attributes, and accessible contrast ratios.
- **Hardware-Accelerated Animation**: Animations and transforms leverage CSS GPU compositing (`transform`, `opacity`) and RAF (`requestAnimationFrame`) loops.
- **Zero Heavy 3D Libraries**: Eliminates Three.js / heavy WebGL bundles by rendering crisp 3D math on lightweight 2D canvas contexts.
